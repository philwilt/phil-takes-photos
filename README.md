# Phil Takes Photos

<img src="public/philtakesphotos-logo.png" alt="Phil Takes Photos Logo" width="100" />

A photography portfolio showcasing surreal and serene moments captured through the lens.

Visit the live site at [philtakesphotos.com](https://philtakesphotos.com)

## About

This site features a curated collection of photography that explores the intersection of the surreal and serene - capturing moments that feel both dreamlike and peaceful. Each gallery presents a unique perspective on landscapes and scenes from around the world.

## Tech Stack

- React 19 + TypeScript
- Vite
- React Router
- Tailwind CSS

## Development

```bash
# Install dependencies
npm install

# Run dev server
npm run dev

# Build for production
npm run build
```
